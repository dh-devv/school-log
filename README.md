# School Log

학교에서 공개를 승인한 일정과 공지사항을 한곳에서 조회하고 검색하기 위한 웹 서비스입니다.

## 프로젝트 현황

현재 요구사항과 기술 설계를 정리하는 단계입니다. 아래 기능은 첫 버전에서 구현할 계획입니다.

- 방문자가 로그인 없이 공개 일정과 공지를 조회하고 날짜·종류별로 검색
- 인증된 관리자가 웹 화면에서 공개 승인된 자료를 등록·수정·삭제
- 관리형 데이터베이스에 자료를 저장하고, 지난 일정도 자동 삭제하지 않고 우선 보관
- 휴대전화와 컴퓨터에서 이용할 수 있는 반응형 화면

첫 버전에는 학생·교사 계정과 반별 비공개 정보를 포함하지 않습니다. 학교의 공개 승인과 권한·백업·복구 검증을 마친 뒤 운영합니다.

## 개발 방식: 바이브 코딩

이 프로젝트는 GitHub Copilot으로 아이디어와 요구사항을 구체화하고, Manus AI를 활용해 개발하는 **바이브 코딩** 방식으로 진행합니다. AI의 결과를 그대로 신뢰하지 않고, 다른 모델의 검토와 직접 확인·시험을 거쳐 수정합니다. 특히 인증, 접근 권한, 데이터 보존과 복구는 실제 운영 전에 검증합니다.

## 기술 구성

- 화면: HTML, CSS, JavaScript
- 화면 배포: GitHub Pages
- 데이터베이스·백엔드: 관리형 서비스 필수. Supabase는 검토 중인 후보입니다.
